## 0. 它的核心主张

不要把问题定义成「估计手机 IMU 移动了多远」，而应定义成
「估计手机上**指定测量头**的位移，并利用测量头的运动约束反过来修正 IMU 的误差」。
三件事（姿态抖动、算 IMU 位置、复杂校准）必须放进同一个物理模型，否则会出现
「滤波更平滑了、距离却更不准」。

## 2. 给开发 AI 的六节指令（原文第二节）

- **一、目标**：测测量头沿直线的净位移，不是积分弧长；禁止过度平滑掩盖真实运动，禁止无条件出数。→ 已体现在引擎的出口判据里。
- **二、统一物理模型**（坐标系/单位/旋转约定写进文档）：→ `docs/v4-head-model.md`、`docs/boundary-design.md`。
- **三、比双锚点更完整的估计方案**（ESKF / 批量平滑 / 把轨迹参数化成 $s(t)$）：→ **试过两条路线，都被否**。见 §3。
- **四、姿态抖动与旋转误差分开处理**：→ 静止段重力校正 + 运动段模长门控；$\alpha$ 差分**明确不采用**。
- **五、时间轴 / 初始化 / 积分方法**：→ 已逐项查过，见 §4。
- **六、物理一致性仿真器**：→ 已建 `sim/simgen.py`（正演 IMU 读数，含杠杆臂），见 §5。

## 3. 它排第三的「带约束批量估计」——**试了，被否**

它认为这是姿态漂移/重力泄漏的主战场。两条路都试了（`sim/batch.py`、`sim/exp_zupt.py`）：

1. **修在姿态层面**：静止段每样本给「重力应竖直」的观测 → 最小二乘解 $\theta(t)=\theta_0+\Delta b\cdot t$（约 380 约束 / 4 未知数）→ 修初始姿态与零偏 → 积分。
   **仿真上输**：T=1.4 s 时 v4 双锚点 +8.0%（σ 7.0）vs 批量 **+47.4%**（σ 13.4）。
2. **用窗口内所有静止样本约束 $v=0$**：**不行** —— 匀速段与静止在加速度计上不可分辨，运动中间的「静止」标记速度**不是零**。仿真 T=1.4 s：只用两端锚点 +23% → 全静止样本 **−52%**。

**为什么必然输（本轮最有价值的新硬事实）**：$\delta p/\delta\theta=\tfrac12 gT^2$。
T=1.4 s 时 1° 姿态误差 → 8.5 cm；而静止段的倾斜观测噪声实测 0.58~1.01° 且**不随样本数下降**。
反推：现有双锚点的残余误差对应的等效倾斜只有 ~0.2°，**姿态层面已经在观测噪声地板上**。
教训：更物理的模型 ≠ 更准的答案，精度由观测噪声决定。

> **估计核因此没有动**，仍是 v4 线性双锚点。动的只有**出口判据**（什么情况下不给数）。

## 4. 它排第一的「时间轴」——**这台设备上不是问题**

实测 4 条真机采集：`dt` 中位数 9.514 ms、σ = 0.000 ms、丢样 0、acc/gyr 交错率 1.00、
相位恒定 2.5 ms。**Android 报的是理想化时间戳，不是真实采样时刻**，所以「用每条样本自身时间戳积分」
在这台设备上没有可积的信息。（换设备要重查。）

⚠ **但有一处真实存在的对齐问题尚未修**：本项目是 acc/gyr **按下标硬对齐**
（`n = min(len(acc), len(gyr))`），实测每条采集有一个**固定**偏移 −21.5 ~ +26.0 ms
（最大 2.7 个样本）。平移修正后距离变化 −0.147 / 0.000 / +0.080 cm —— **该修，
但只有 0.1 cm 量级，排在硬真值采集之后**。

## 5. 它的细节 B（$\alpha$ 差分放大噪声）与 C（仿真与验证）

- **细节 B**：$a_H=a_I+R(\alpha\times r+\omega\times(\omega\times r))$ 里的 $\alpha$ 要对带噪陀螺做差分。
  项目**没有走这条路**，改用位置层面的 $\Delta R\cdot r$（只用到两端姿态，不放大噪声）。→ 已按它的建议办。
- **细节 C**：仿真器已建（`sim/simgen.py`，含杠杆臂、白噪声/零偏/游走/比例因子/量化/低通/采样抖动/丢样/acc-gyr 时差；
  用 smoothstep 保证角速度连续 —— 线性 slerp 会造出 47 m/s² 的假冲击）。
  ⚠ **但仿真器自身还有一处标定错误未修**：`gyr_noise` 用了 0.002，真机实测 0.0005~0.0008（**高约 3 倍**）；
  `gyr_bias_rw=0.02` 来自 P90 统计（被少数假静止段主导）而真机**无游走**（76 s 静止录制，Allan 单调下降无平台）。
  **重标之前，仿真不能用来 accept/reject 估计器。**

## 7. 它没提到、但本项目自己撞出来的（补充）

- **终点锚点会失效**：松手 ≠ 停住，匀速与静止不可分辨 → 双锚点把真实位移当漂移扣掉
  （143734：裸积分 16.19 cm 本来是对的）。已加诊断 `anchorSuspect`。
- **起点锚点质量**：`startTremorRadS` 按场次分层 30~170 倍（桌面 0.0001~0.0004 vs 手持 0.012~0.020），**只诊断不判**。
- **统计量一律用中位数**：真机重尾分布，RMS/中位数 = 7~50 倍，RMS 会被少数假静止段主导。
- **结论强度三级标记**（`sim/README.md` §0.5）：`[实测 N=k]` / `[仿真]` / `[外推]`；引擎与界面只准放实测量。
