# 02 · 姿态滤波选型（互补 / Madgwick / Mahony）

目的回顾：姿态在这里只为**一件事**服务——把重力从比力里干净地剥掉（见 01 号：1° 姿态误差 = 0.17 m/s² 假加速度）。yaw 不需要（一维投影不依赖航向）。

## 三个候选

### 互补滤波（Complementary）
- 原理：陀螺积分（高通，短期可信）+ 加速度计测重力方向（低通，长期可信），按增益 α 混合
- 优点：~10 行代码，每个参数的行为可解释、可单独调
- Hanafi et al. 2019 (IOP, *Multi-sensory data fusion for high performance attitude estimation*)：**静止和稳态场景下互补滤波效率优于 Mahony**
- 缺点：增益固定，动态适应性差

### Madgwick（2010）
- 梯度下降单体融合，把陀螺积分与加速度/磁力计参考统一到一个优化目标里
- 计算量小（最初就是为低端 MCU 设计），一个 β 参数
- 参考实现：`arduino-libraries/MadgwickAHRS`（585★，Arduino 官方库，C 源码可读，最方便的算法参照物）
  - x-io 原始仓库已迁移，官方 PDF 报告 `x-io.co.uk/res/doc/madgwick_internal_report.pdf` **已 404**（抓取于 2026-10-05），需找镜像
- 先例：Wojtek 的 IMU 位移项目用的就是 Madgwick（见 05 号），跑通了全链路

### Mahony（2009）
- PI 控制器形式的互补滤波，显式估计并补偿陀螺零偏
- 优点：零偏内建补偿（对我们要校准零偏的需求很对口）
- 缺点：两个参数（Kp/Ki）要调

## 对比研究结论（搜索件 `_raw/q3_filter.json`）

- Hanafi 2019：静止/稳态 → 互补占优；动态大机动 → Mahony/Madgwick 更稳
- RIANN (arXiv 2021)：神经网络姿态估计在基准上超过传统滤波器——**对我们过重，忽略**
- 多项四旋翼 AHRS 对比（sciencepubco 等）：Madgwick 与 Mahony 精度同量级，选择看工程口味

## 选型建议（供开工时拍板）

**第一版用互补滤波，Mahony 做第二候选**：

1. 我们场景是"准静态贴桌滑动"，不是四旋翼大机动——互补滤波的最有利区间
2. 互补滤波的 α 就一个旋钮，真机盲调阶段可解释性值千金
3. 陀螺零偏我们自己有 2 秒静止校准段兜底，Mahony 的内建补偿优势减弱
4. Madgwick 作为备胎：Wojtek 同场景跑通的证据，且 Arduino 官方库可对照移植

**本质洞察：yaw 不可观不是缺陷。** 无磁力计时 yaw 必漂，但一维投影只需要 pitch/roll 把重力剥干净——yaw 漂移对结果**零影响**。选型时不必为 yaw 稳定性付任何复杂度成本。这也是不必上磁力计的依据（spec 说"必要时融合磁力计"——大概率不必要）。
